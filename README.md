# Bio Generator Pro

Professional bio generator for social media platforms with free and Pro tiers.

## Features

- Platform Selection: LinkedIn, Instagram, Twitter/X, Telegram, TikTok
- Template-Based Generation: 4 free tones + 3 Pro tones
- ChatGPT Integration: AI-powered bio generation (Pro only)
- Hashtag Generator: relevant hashtags based on profession
- Usage Tracking: daily and total generation counters
- History: view and reuse previous bios
- Ready-to-use examples for 8 professions
- Export: copy, download as PNG, email placeholder
- Pro Features (one-time $9 via bazium.ru): unlimited, ChatGPT, all tones, no watermark

## Installation

1. Open `index.html` in any modern browser
2. Deploy to Vercel/Netlify/GitHub Pages for public access

## Pro Activation

1. Click "Получить Pro" → redirected to bazium.ru
2. After purchase, returned with `?pro=activated` in URL
3. App auto-detects and unlocks Pro

## ChatGPT Setup (Pro)

1. Get API key at platform.openai.com/api-keys
2. Click the key icon in the app (or it will prompt when generating)
3. Enter and save key (stored in localStorage)
