# Bio Generator

A simple web app that generates catchy bios for social media profiles (LinkedIn, Twitter, Instagram, etc.) based on profession, hobby, and desired tone.

## Features
- Free tier: 3 generations per day.
- Pro tier ($9 one-time): Unlimited generations, extra tones (mysterious, inspiring, concise), no watermark, ability to save favorites.
- Client-side only: No server needed, works offline after initial load.
- Easy to deploy: Static HTML/CSS/JS can be hosted on Vercel, Netlify, GitHub Pages, or any static host.

## How to run locally
1. Open `index.html` in a browser.
2. Fill in profession, interest (optional), select tone.
3. Click "Сгенерировать bio".
4. Copy the result or generate another.

## How to deploy
- Upload the folder contents to any static web host (Vercel, Netlify, GitHub Pages, Firebase Hosting, etc.).
- Ensure the site is served over HTTPS for proper clipboard API (optional but recommended).
- Optionally add a custom domain.

## Monetization
- Use Gumroad or Lemon Squeezy to sell a digital product "Bio Generator Pro" for $9.
- After purchase, redirect the user to a thank-you page that sets a flag in localStorage (or checks via URL parameter) to unlock Pro features.
- In this starter, Pro unlock is simulated: after Gumroad purchase, the user should return to the site and the Pro flag can be set manually via a query parameter (`?pro=true`) or by entering a token. For a production version, implement a simple verification via a webhook or check the redirect URL.

## Customization
- Edit the `templates` and `proTemplates` objects in `app.js` to add more bio variations.
- Modify `style.css` to change colors, fonts, or layout.
- Add more input fields (e.g., emoji preference, hashtags) if desired.
