# Bio Generator Pro

Профессиональный генератор био для соцсетей с бесплатным и Pro-доступом.

## ✨ Возможности

- 🎯 Выбор платформы: LinkedIn, Instagram, Twitter/X, Telegram, TikTok
- 🎨 4 бесплатных тона + 3 эксклюзивных для Pro
- 🤖 Генерация через ChatGPT (только Pro)
- #️⃣ Авто-генерация хэштегов
- 📊 Счётчик генераций (сегодня / всего)
- 🕐 История последних био
- 💾 Экспорт: копирование, скачивание как картинка
- 🔐 Активация Pro через ссылку `?pro=activated`

## 🚀 Быстрый старт

1. Открой `index.html` в браузере
2. Или задеплой на [Vercel](https://vercel.com) / [Netlify](https://netlify.com)

## 💳 Покупка Pro

1. Нажми «Получить Pro» на сайте
2. Оплати через [Lava.top](https://lava.top)
3. После оплаты перейди по ссылке из письма:  
   `https://твой-сайт.vercel.app/?pro=activated`
4. Pro-функции разблокируются автоматически!

## 🔑 Настройка ChatGPT (для Pro)

1. Получи API ключ: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
2. Нажми на иконку 🔑 в приложении
3. Вставь ключ (сохраняется локально в браузере)
